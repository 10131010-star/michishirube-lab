チェック方法

Unityで該当箇所を見ながら、各項目を「気になる / 問題なし / 未確認」で選び、最後に結果を表示してください。

この手動チェックは参考情報です。すべて「問題なし」でも実機動作やVRChatでの互換性は保証しません。

5つの確認ポイント

1. Animator Layerの重複

同じ役割のLayerが重複していないか、名前と構成を見直す。

2. Write Defaultsの混在

対象ステート間でWrite Defaultsの設定が不必要に混在していないか。

3. 不審なTransition

状態削除・変更後に遷移先がおかしいTransitionが残っていないか。

4. ConditionのParameter

Transition条件で参照するParameterが定義されているか。

5. 未使用Parameter

未使用に見えるParameterの用途を、他の参照元も含め確認したか。

Unity上でさらに確認したい方へ：この無料チェックは手動の整理用です。Animator Controllerの状態を読み取り専用でレポート化するAnimator Doctor Proの商品詳細（有料・先行版）も確認できます。自動修復は行わず、未検証環境での動作は保証しません。

VERIFIED UNITY EXAMPLE / NOT A COMMERCIAL AVATAR

実例：Animatorの「未定義Parameter」とWrite Defaults混在をどう見つける？

「衣装の切替が動かない」「遷移条件が正しいか分からない」という方向けに、Unity上で実際に検証したテスト用Controllerの診断例を紹介します。これは不具合を意図的に含む合成データで、実在の市販アバターの診断結果ではありません。

  1. Unityで対象の Animator Controller を開き、Transitionの Conditions と Parameters タブを見比べます。EntryやAny Stateなどの遷移も確認対象です。
  2. 実機検証に使った RC3_Demo_A では、Base Layer/Entry → Idle の条件が参照する MissingEntryParameter がControllerに定義されていないことが検出されました（NAD004 / Error）。無料チェックでは4番「ConditionのParameter」を「気になる」として記録できます。
  3. 同じControllerでは Write Defaults ON 1件 / OFF 1件の混在（NAD002 / Warning）と、遷移条件から未参照の ReviewUsage（NAD005 / Info）も確認されました。未使用の表示だけでParameterを削除しないでください。

CHECK BEFORE EDITING / 3 COMMON CASES

よくある3つのつまずきと確認順

まずUnityプロジェクトをバックアップし、症状が起きる条件を控えてください。ここで紹介するのは切り分けの手順であり、自動修復・原因の確定ではありません。

Q1. 衣装や表情の切り替え後、元の表示に戻らない

  1. 該当するステートの Write Defaults が混在していないか確認する。
  2. 次のステートに戻す値を設定するAnimation Clipがあるか確認する。
  3. 一律にOn/Offを変更せず、AdditiveやDirect Blend Treeなどの例外も含めて設定を見直す。

参考：VRChat公式：Write Defaults。VRChatは基本的に設定を揃えることを勧めていますが、例外があります。

Q2. Expressions Menuの操作で期待した動きにならない

  1. Expressions MenuのControlが指定するParameter名・型を確認する。
  2. Avatar Descriptorに割り当てたExpression ParametersとAnimator側の定義を見比べる。
  3. VRChat標準の組み込みParameterと自作Parameterを混同していないか確認する。

参考：VRChat公式：Expressions Menu／Animator Parameters。

Q3. 表情と衣装のアニメーションが干渉する

  1. Avatar DescriptorのPlayable Layers（Base / Additive / Gesture / Action / FX）を確認する。
  2. 意図せず同じプロパティを複数レイヤーから操作していないか確認する。
  3. 特にFXレイヤーの役割とAvatar Maskを確認し、変更前の設定を保存してから1箇所ずつテストする。

参考：VRChat公式：Playable Layers。

症状の切り分けに迷ったら、上の5項目チェックで「気になる」を記録し、コピーしたメモを自分のUnity作業に使ってください。手動確認から一歩進めたい場合にのみ、上記の有料版の仕様と対応環境を確認してください。
