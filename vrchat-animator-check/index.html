チェック方法

Unityで該当箇所を見ながら、各項目を「気になる / 問題なし / 未確認」で選び、最後に結果を表示してください。

この手動チェックは参考情報です。すべて「問題なし」でも実機動作やVRChatでの互換性は保証しません。

5つの確認ポイント

1. Animator Layerの重複

同じ役割のLayerが重複していないか、名前と構成を見直す。

2. Write Defaultsの混在

対象ステート間でWrite Defaultsの設定が不必要に混在していないか。

3. 不審なTransition

状態削除・変更後に遷移先がおかしいTransitionが残っていないか。

4. ConditionのParameter

Transition条件で参照するParameterが定義されているか。

5. 未使用Parameter

未使用に見えるParameterの用途を、他の参照元も含め確認したか。

    CHECK BEFORE EDITING / 3 COMMON CASES

    よくある4つのつまずきと確認順

    まずUnityプロジェクトをバックアップし、症状が起きる条件を控えてください。ここで紹介するのは切り分けの手順であり、自動修復・原因の確定ではありません。

    Q1. 衣装や表情の切り替え後、元の表示に戻らない

    1. 該当するステートの Write Defaults が混在していないか確認する。
    2. 次のステートに戻す値を設定するAnimation Clipがあるか確認する。
    3. 一律にOn/Offを変更せず、AdditiveやDirect Blend Treeなどの例外も含めて設定を見直す。

    参考：VRChat公式：Write Defaults。VRChatは基本的に設定を揃えることを勧めていますが、例外があります。

    Q2. Expressions Menuの操作で期待した動きにならない

    1. Expressions MenuのControlが指定するParameter名・型を確認する。
    2. Avatar Descriptorに割り当てたExpression ParametersとAnimator側の定義を見比べる。
    3. VRChat標準の組み込みParameterと自作Parameterを混同していないか確認する。

    参考：VRChat公式：Expressions Menu／Animator Parameters。

    Q3. AnimatorのTransitionが動かない・元のステートに戻れない

    1. UnityのAnimatorウィンドウで、戻りたいステートへつながるTransitionの線を選択し、InspectorのConditionsにあるParameter名・条件値を確認します。ControllerのParametersに同名の定義があるかも比較します。
    2. Has Exit Timeが有効なら、条件が正しくても指定されたExit Timeに達するまで遷移しない場合があります。無効化を決めつけず、アニメーション再生時間・ループ・必要な動作タイミングを先に確認します。
    3. 戻り先へつながる遷移自体があるか、Any State / Entry / 子StateMachine側に関連条件がないかを調べます。設定を変える前にControllerをバックアップし、一度に1項目ずつ再確認してください。

    参照：Unity 2022.3公式：アニメーション遷移（Exit Time・Conditions）／VRChat公式：Animator Parameters。無料チェックは症状の手動整理のみ。有料版で確認したのは遷移条件に関する候補検出であり、Exit TimeやVRChat内の復帰動作を自動で検証する機能はありません。検証用Controllerの実例と機能差を確認。

    Q4. 表情と衣装のアニメーションが干渉する

    1. Avatar DescriptorのPlayable Layers（Base / Additive / Gesture / Action / FX）を確認する。
    2. 意図せず同じプロパティを複数レイヤーから操作していないか確認する。
    3. 特にFXレイヤーの役割とAvatar Maskを確認し、変更前の設定を保存してから1箇所ずつテストする。

    参考：VRChat公式：Playable Layers。

    症状の切り分けに迷ったら、上の5項目チェックで「気になる」を記録し、コピーしたメモを自分のUnity作業に使ってください。手動確認から一歩進めたい場合にのみ、上記の有料版の仕様と対応環境を確認してください。

    BEFORE YOU BUY / FAQ

    無料チェックと有料版、使う前によくある質問

    Q. 無料チェックだけでも使えますか？

    はい。登録・購入・Unityファイルのアップロードは不要です。UnityのAnimator Controllerを自分で見ながら5項目を選び、「気になる」「未確認」を確認メモとして残せます。結果が「問題なし」でも正常動作の保証ではありません。

    Q. Expressions Menuの不具合も自動検出しますか？

    いいえ。無料チェックも有料のAnimator Doctor Proも、Expressions Menu全体の自動診断や不具合の原因確定には対応しません。まずControl、Expression Parameters、Animatorの名前と型を手動で照合してください。具体的な確認順はこちら。

    Q. どのUnity・SDKで確認されていますか？

    公開済みの検証記録はWindows、Unity 2022.3.22f1、VRChat SDK Base・Avatars 3.10.5でのテスト用Controllerに関するものです。ほかのUnity・SDK、市販アバターやModular Avatarとの組み合わせは未検証で、対応を保証しません。検証例と無料・有料の機能差を購入前に確認してください。

    Q. Animator Doctor Proは自動修復しますか？

    自動修復しません。Unity Editor内で選んだAnimator Controllerを読み取り専用で点検し、確認候補を日英UI・Markdownレポートで整理する先行版です。修正はバックアップ後に利用者が判断して行います。購入は任意です。
