## 事業仮説
個人運営の美容・リラクゼーション・ネイルサロンは、直前キャンセル対応に手間と機会売上の損失がある。外部APIや個人情報の管理を必要としない軽量な対策ツールと文面セットに、小額の支払意思があるか検証する。これは既存のWeb制作、Kindle、VRChat、ゲーム、SNS、YouTubeとは別の「サロン運営改善ツール」事業の検証であり、現段階で有償需要は未確認。

## 価格と検証条件
- 対象：1〜5名規模の予約制個人サロン（美容室・ネイル・リラクゼーション）
- 無料導線：上記HTMLを配布して課題認識と文面の使い勝手を確認
- 有料候補：無料版とは別の7日間集計ツール（CSV入出力・入力検証）、導入手順、文面、記録用シート、店舗向け運用キットを **税込1,480円（提案価格）**
- 初期合格：実際に対象者3名以上の有効反応、または購入意向1名以上を2026-11-19までに確認
- 反応0件・購入意向0件：価格/商品訴求を一度見直し、改善根拠がなければ撤退
- 初売上：実際の決済画面・通知でのみ確定し、仮説を実績に混ぜない

## 競合・市場（引用・事実区分）
リザービアが2026年に公表した調査では、対象のサロン予約データでキャンセルの43.2%が前日・当日に集中した（調査サンプルの結果であり全サロン平均ではない）。<https://rsvia.co.jp/report/salon_reservation_cancellation_2026h1/>
同社発表の別調査ではWeb予約のキャンセル率17.61%、無断キャンセル率1.80%と報告された。対象期間・予約経路に依存するため試算ツールの初期値にこの数字は転記していない。<https://prtimes.jp/main/html/rd/p/000000009.000035976.html>
既存の無料対策情報もあるため、有料化には「すぐ使える個店向けの使いやすさ」と実際の購入意向検証が必要。
