投稿 IG-D002 のテンプレート

VLOOKUPでやりがちなミス3つ

XLOOKUPなら1本で解決。ミスの理由と、そのまま使える式・練習用の表です。

ミス① 最後の引数を省略

=VLOOKUP(A2,商品!A:C,3)
→ 省略すると「近似一致」になり
　違う商品の値が返ることがある
正しくは最後に FALSE を付ける

ミス② 列番号の「3」がずれる

表に列を1本挿入すると
「3列目」が別の列を指す
→ 気づかないまま間違った値に

ミス③ 左側の列を引けない

VLOOKUPは「検索する列が左端」が前提
商品名からコード（左側）を
引きたいときに使えない

XLOOKUPならこう書く

=XLOOKUP(A2, 商品マスタ!$A$2:$A$500, 商品マスタ!$C$2:$C$500, "該当なし")

A2 … 探す値（商品コード）
1つ目の範囲 … 探す列
2つ目の範囲 … 返したい列
"該当なし" … 見つからない時の表示

3つのミスが消える理由

① 何も指定しなければ完全一致
② 返す列を範囲で指定 → 列挿入に強い
③ 返す列が左側でもOK
＋見つからない時の表示も1本で

XLOOKUPがない環境では（Excel 2019以前など）

=IFERROR(INDEX(商品マスタ!$C$2:$C$500, MATCH(A2, 商品マスタ!$A$2:$A$500, 0)), "該当なし")

※XLOOKUPはMicrosoft 365／Excel 2021以降とGoogleスプレッドシートで使えます

AIに書かせるときの頼み方

「商品マスタ」シートのA列（A2:A500）が商品コード、C列が単価です。
今のシートのA2の商品コードで単価を引くXLOOKUPを書いてください。
見つからない時は「該当なし」と表示。
範囲は絶対参照にしてください。

練習用のサンプル表：新しいスプレッドシートに「商品マスタ」「注文」の2シートを作り、それぞれA1セルに貼り付けてください（P099はマスタにないため「該当なし」になります）。

投稿 IG-D003 のテンプレート

期限が近いタスク、毎朝メールで届く

コピペOK｜Googleスプレッドシート＋GAS。期限が今日・明日のタスクを、毎朝自分宛てにメールで知らせます。

できること

・期限が「今日・明日」のタスクを
　毎朝8時台に自分へメール
・期限切れには【期限切れ】と表示
・該当がない日は送らない

① シートを用意

シート名：タスク
A列 タスク名／B列 担当
C列 期限（日付で入力）
D列 状態（「完了」で通知しない）
1行目は見出し

シートの雛形（「タスク」シートのA1に貼り付け）

タスク名	担当	期限	状態

② コードを貼る

「拡張機能」→「Apps Script」を開く
最初からあるコードを消す
下のコード全文をコピーして貼り、保存

コード全文

// 期限が近いタスクを毎朝メールで自分に通知する
// シート「タスク」：A=タスク名 B=担当 C=期限（日付） D=状態（「完了」で通知対象外）
const SHEET_NAME = 'タスク';
const DAYS_AHEAD = 1; // 1 = 今日と明日が期限のもの（期限切れも含む）

function notifyDueTasks() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(SHEET_NAME);
  if (!sheet) throw new Error('シート「' + SHEET_NAME + '」が見つかりません');

  const today = new Date();
  today.setHours(0, 0, 0, 0);
  const limit = new Date(today);
  limit.setDate(limit.getDate() + DAYS_AHEAD);

  const rows = sheet.getDataRange().getValues().slice(1); // 1行目は見出し
  const lines = [];
  rows.forEach(function (row) {
    const task = row[0], owner = row[1], due = row[2], status = row[3];
    if (!task || status === '完了' || !(due instanceof Date)) return;
    if (due > limit) return;
    const mark = due < today ? '【期限切れ】' : '';
    const day = Utilities.formatDate(due, Session.getScriptTimeZone(), 'M/d');
    lines.push(mark + day + ' ' + task + '（' + (owner || '担当未定') + '）');
  });
  if (lines.length === 0) return; // 該当なしの日は送らない

  MailApp.sendEmail({
    to: Session.getEffectiveUser().getEmail(),
    subject: '【期限通知】' + lines.length + '件',
    body: lines.join('\n') + '\n\n' + ss.getUrl()
  });
}

// 最初に1回だけ実行：毎朝8時台に notifyDueTasks を動かすトリガーを作る
function createMorningTrigger() {
  ScriptApp.getProjectTriggers().forEach(function (t) {
    if (t.getHandlerFunction() === 'notifyDueTasks') ScriptApp.deleteTrigger(t);
  });
  ScriptApp.newTrigger('notifyDueTasks').timeBased().everyDays(1).atHour(8).create();
}

③ 動かす

createMorningTrigger を選んで「実行」
自分のアカウントで権限を許可
試すなら notifyDueTasks を実行

つまずきやすい所

・C列は文字でなく日付で入力
・タイムゾーンは東京に設定
・「確認されていません」は詳細→許可

宛先は自分のアドレスだけで、ほかの人には送られません。会社のアカウントで使う場合は、社内ルールでGASの利用が認められているか先に確認してください。

職務経歴書の「AI使えます」、こう書く

型と例文3つ。「ChatGPTを使えます」だけで終わらせない書き方です。

NG：「ChatGPTを使えます」

何の仕事に、どう使い
何が良くなったかが伝わらない
→ 読む人が判断できない

書き方の型

業務 → AIの使い方
→ 自分の確認・工夫 → 結果（数字）
「確認・工夫」を入れると
AI任せではないことが伝わる

例文①　事務

週次の売上報告で、AIを使い集計コメントの下書きを作成。数値は元データと照合して確認し、作成時間を約60分→約20分に短縮（自己計測）

例文②　営業

提案書の構成案をAIで3案作成し、顧客の課題に合わせて1案に絞り込み。上長レビューを経て、提案書作成の手順をチーム内で共有

例文③　企画

アンケートの自由記述（約300件）をAIで分類。分類結果は1割を抜き取りで目視確認し、改善テーマの洗い出しを約2日→約半日に短縮（自己計測）

※例文は見本です。ご自身の実際の業務と数字に置き換えてください。例文の数字は見本で、実在の人物の実績ではありません。

数字の出し方

・作業の前後で、かかった時間を
　1〜2週間メモする
・「約」「自己計測」を付けて正直に
・盛ると面接の深掘りで困る

/**
 * 定型メール自動送信テンプレート（Googleスプレッドシート + Apps Script）
 * 配布：ミチシルベ業務ラボ（無料・改変自由）
 *
 * 【準備】
 * 1. スプレッドシートに「送信リスト」シートを作り、1行目に見出しを入れる
 *    必須：メールアドレス / 名前 / 送信状況   任意：会社名 など自由に追加OK
 * 2. 拡張機能 → Apps Script を開き、このコードを貼り付けて保存
 * 3. まず DRY_RUN = true のまま sendMails を実行 → 実行ログで文面を確認
 * 4. 問題なければ DRY_RUN = false にして実行（送信した行に「送信済み」が入る）
 * 5. 毎朝自動で送るなら setupDailyTrigger を1回だけ実行
 *
 * 件名・本文の {見出し名} は、その行の値に置き換わります（例：{名前}）。
 * 「送信状況」が空の行だけ送るので、同じ人に二重に送りません。
 */

// ===== ここを書き換える =====
var SHEET_NAME = '送信リスト';
var SUBJECT = '【ご案内】{名前}様 来週の定例会について';
var BODY = [
  '{会社名}',
  '{名前} 様',
  '',
  'いつもお世話になっております。',
  '来週の定例会の資料をお送りします。',
  'ご不明点があれば、このメールにご返信ください。',
  '',
  'よろしくお願いいたします。'
].join('\n');
var DRY_RUN = true;     // true の間は送信せず、実行ログに文面を出すだけ
var MAX_PER_RUN = 20;   // 1回の実行で送る上限（送りすぎ防止）
var TRIGGER_HOUR = 9;   // setupDailyTrigger で毎日実行する時（0〜23）

// ===== 本体 =====
function sendMails() {
  var lock = LockService.getScriptLock();
  if (!lock.tryLock(10000)) {
    console.log('前回の処理が実行中のため、スキップしました');
    return;
  }
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME);
    if (!sheet) throw new Error('「' + SHEET_NAME + '」シートがありません');
    var values = sheet.getDataRange().getValues();
    var header = values[0].map(function (h) { return String(h).trim(); });
    var col = {};
    header.forEach(function (h, i) { col[h] = i; });
    ['メールアドレス', '名前', '送信状況'].forEach(function (k) {
      if (!(k in col)) throw new Error('1行目に見出し「' + k + '」がありません');
    });

    var limit = Math.min(MAX_PER_RUN, MailApp.getRemainingDailyQuota());
    var count = 0;
    for (var r = 1; r < values.length && count < limit; r++) {
      var row = values[r];
      var to = String(row[col['メールアドレス']]).trim();
      if (!to || String(row[col['送信状況']]).trim() !== '') continue;
      var statusCell = sheet.getRange(r + 1, col['送信状況'] + 1);
      if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(to)) {
        if (!DRY_RUN) statusCell.setValue('エラー：アドレスの形式');
        console.log((r + 1) + '行目：アドレスの形式が不正のためスキップ');
        continue;
      }
      var subject = fill_(SUBJECT, header, row);
      var body = fill_(BODY, header, row);
      count++;
      if (DRY_RUN) {
        console.log('[テスト・未送信] ' + (r + 1) + '行目 宛先：' + to + '\n件名：' + subject + '\n' + body);
        continue;
      }
      try {
        MailApp.sendEmail(to, subject, body);
        statusCell.setValue('送信済み ' + Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy/MM/dd HH:mm'));
      } catch (e) {
        statusCell.setValue('エラー：' + e.message);
      }
    }
    console.log((DRY_RUN ? 'テスト完了（未送信）：' : '送信完了：') + count + '件');
  } finally {
    lock.releaseLock();
  }
}

// {見出し名} をその行の値に置き換える（見出しにない名前はそのまま残す）
function fill_(text, header, row) {
  return text.replace(/\{([^{}]+)\}/g, function (m, key) {
    var i = header.indexOf(key.trim());
    return i === -1 ? m : String(row[i]);
  });
}

// 毎日 TRIGGER_HOUR 時台に sendMails を自動実行する（重複しないよう先に削除）
function setupDailyTrigger() {
  deleteTriggers();
  ScriptApp.newTrigger('sendMails').timeBased().everyDays(1).atHour(TRIGGER_HOUR).create();
  console.log('毎日' + TRIGGER_HOUR + '時台に自動実行します');
}

// 自動実行をやめる
function deleteTriggers() {
  ScriptApp.getProjectTriggers().forEach(function (t) {
    if (t.getHandlerFunction() === 'sendMails') ScriptApp.deleteTrigger(t);
  });
}

「送信状況」が空の行だけに送るため、同じ人へ二重には送りません。初回の実行時に、Googleから権限の確認画面が表示されます（スプレッドシートの編集・メール送信・自動実行の設定）。1日に送れるメールの数にはGoogle側の上限があります。社外への一斉送信は、勤務先のルールを確認してから使ってください。広告・宣伝のメールを送る場合は特定電子メール法（同意の取得、送信者情報と配信停止方法の表示）に従ってください。
